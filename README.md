# 💬 Multi-Client Chat Application (Java)

## 📌 Project Overview

This project is a **Multi-Client Chat Application** built using **Java Socket Programming**. It allows multiple users (clients) to connect to a central server and communicate with each other in real time.

The project demonstrates core concepts of **Computer Networks, Multithreading, and Object-Oriented Programming (OOP)** in Java.

---

## 🚀 Features

* 🔗 Multiple clients can connect to a single server
* 💬 Real-time message broadcasting
* 🧵 Multi-threading for handling multiple users
* 🔄 Continuous communication between server and clients
* ⚡ Lightweight and fast execution

---

## 🧠 Concepts Used

* Java Socket Programming
* Multithreading
* Input/Output Streams
* Client-Server Architecture
* Exception Handling

---

## 📂 Project Structure

```
ChatApp/
│
├── Server.java          # Starts the server and accepts clients
├── Client.java          # Connects user to the server
├── ClientHandler.java   # Handles communication between clients
```

---

## ⚙️ How to Run the Project

### 1️⃣ Compile the files

```bash
javac Server.java
javac Client.java
javac ClientHandler.java
```

### 2️⃣ Start the Server

```bash
java Server
```

### 3️⃣ Run Clients (in different terminals)

```bash
java Client
```
